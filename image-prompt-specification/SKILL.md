# 四维意图与按需补细节

## R — 原文 (Reading)

> 过于简短模糊的提示词，会导致 AI 猜你；生成的结果就会变得非常随机。把提示词写得详细、精确就显得尤为重要。
>
> — Tim，00:07:55–00:08:12

> 思维导图是帮你查漏补缺的工具，不是束缚你的模板；你需要什么就写什么，不需要的就跳过。
>
> — Tim，00:11:26–00:11:33

---

## I — 方法论骨架 (Interpretation)

把一条图片提示词视作对视觉不确定性的规格说明，而非越长越好的一串形容词。

先用四个维度定位画面意图：**时间**决定年代、季节、时刻及其光影线索；**主体**决定观众首先看谁或什么；**场景**提供环境、行为和叙事条件；**风格**约束质感、情绪、构图、镜头和视觉媒介。

然后只补会改变任务成败的字段。棚拍白底产品不必硬写清晨或黄昏；纯风景可能没有主体；图标、Logo、二维动画也需要更少字段。目标是消除关键歧义，避免模型代替用户做重要决定。

## A1 — 书中的应用 (Past Application)

### 案例 1：从“一名武林大侠”到电影设定图

- **问题**：一句主体描述会生成游戏、插画等不稳定结果。
- **方法论的使用**：课程把武侠画面逐步放入时间、主体、场景与风格的描述中。
- **结论**：关键画面信息需要被显式表达，而非交给模型猜测。
- **结果**：画面意图更集中，后续可据此继续修正。

### 案例 2：不同任务删去不同维度

- **问题**：学习者容易把思维导图误认为必填表。
- **方法论的使用**：课程对棚拍白底产品省略时间/场景，对纯风景省略主体，对平面图形减少字段。
- **结论**：导图用于查漏补缺，不用于机械填空。
- **结果**：提示词更贴合任务，避免无意义的复杂化。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 只有一个粗略画面想法，却希望生成结果稳定、可复现。
2. 多次出图后发现主体、场景、时间感或风格总有一项跑偏。
3. 要把创意简报、商品需求或分镜意图改写为文字生图提示词。
4. 不确定某个字段该补充还是该省略。

### 语言信号 (用户的话里出现这些就应激活)

- “帮我把这个画面想法写成提示词。”
- “为什么同一句提示词每次画风都不一样？”
- “我还需要补哪些细节？” / “Which prompt details are missing?”
- “帮我优化 image prompt，让它别跑偏。”

### 与相邻 skill 的区分

- 与 `reference-image-prompt-reverse-engineering` 的区别：本 skill 从文字意图或简报出发；后者以一张现成参考图为证据起点。
- 与 `constraint-aware-prompt-expansion` 的区别：本 skill 先定义必要约束；后者决定是否把已定义的约束交给 AI 自由扩写。

## E — 可执行步骤 (Execution)

1. **写出任务的成功画面与不可接受偏差**
   - 至少明确用途、主视觉焦点和 2–5 个不可变条件。
   - 完成标准：能说清“什么结果算对、什么结果算跑偏”。

2. **按四维查漏并裁剪**
   - 时间：年代/季节/时刻或光影；主体：身份、外观、姿态；场景：环境和关系；风格：媒介、氛围、色调、构图/镜头。
   - 对每一维标为“必须指定、可选、应省略”。
   - 完成标准：每一项都能说明它会如何改变画面；不能说明影响的字段不写。

3. **输出分层提示词并复核歧义**
   - 先写一句核心画面，再补必须细节；如平台支持，可把负面约束单列。
   - 完成标准：任一关键约束都能在提示词中找到对应文字；不含为凑长度而加的冲突描述。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户的唯一目标是从一张具体图片反推出可比较的描述：先用 `reference-image-prompt-reverse-engineering`。
- 用户明确要大量风格方向、接受人物/服装等细节变化：先用 `constraint-aware-prompt-expansion` 选择探索模式。
- 任务是纯技术参数查询或对已完成提示词做拼写校对，不需要视觉意图诊断。

### 作者在书中警告的失败模式

- 过短、模糊的提示词把关键选择交给模型，造成随机结果、反复生成与额外成本。
- 将导图当成每次必填模板，会在白底产品、风景或平面设计任务中引入无关信息。

### 作者的盲点 / 时代局限

- 四维框架未覆盖平台特有控制项，例如种子、参考强度、区域控制或版权/商标限制。
- “电影感”“高质量”等风格词有明显的模型、文化与审美依赖，不能被当作客观标准。

### 容易混淆的邻近方法论

- 对参照图的拆解属于证据反推，不等于从零规格化。
- 对 AI 扩写的验收属于控制权决策，不等于补齐四维。
