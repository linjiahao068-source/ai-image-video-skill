# 参照图的证据化反推

## R — 原文 (Reading)

> 有了这张思维导图，你还可以用它反推提示词。看到一张喜欢的图，照着上面的要素，自己试着去反推一下图片的提示词。
>
> — Tim，00:11:40–00:12:02

> 目前的 AI 还没有这么强大，它反推提示词生成出来的图，并不会完全像我们之前的那张图。
>
> — Tim，00:13:40–00:13:46

---

## I — 方法论骨架 (Interpretation)

反推参考图不是猜出一段“原始提示词”，而是把图片中可观察的线索转成可测试的视觉假设。

先记录看得见的事实，再记录推断和不确定项；随后用时间、主体、场景、风格重组出一份目标提示词。生成后以目标特征逐项比较，决定修改哪一维。这样能学习可迁移的观察方法，也能避免把“相近结果”误解为“精确复刻”。

## A1 — 书中的应用 (Past Application)

### 案例 1：观察一张武侠人物图

- **问题**：学习者需要从已有图像中理解如何写提示词。
- **方法论的使用**：课程要求按时间、主体、场景、风格描述傍晚光线、人物、白色服装、环境和电影感等线索。
- **结论**：参考图可以被分解为结构化视觉信息。
- **结果**：学习者有可重复的反推练习路径。

### 案例 2：让 Agent 先反推，再人工修正

- **问题**：手动复制提示词到生成节点效率较低。
- **方法论的使用**：Agent 可以分析图并生成，但课程随即提示结果不会完全像原图。
- **结论**：AI 反推只是初稿，使用者必须知道如何判断和修改。
- **结果**：效率提高，但不会误把自动输出当作高保真复刻。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 给出一张喜欢的图片，想写出相近气氛或构图的生成提示词。
2. 想把收藏图、海报、摄影参考转成可编辑的视觉要求。
3. AI 已给出图像描述，但用户需要核对遗漏、冲突或不可确认的内容。

### 语言信号 (用户的话里出现这些就应激活)

- “帮我反推这张图的提示词。”
- “分析这张参考图是什么风格/构图/光线。”
- “我想做同样氛围，但不要一模一样。”
- “Derive a prompt from this reference image.”

### 与相邻 skill 的区分

- 与 `image-prompt-specification` 的区别：本 skill 由图片证据驱动，并显式处理不确定性；后者由文字需求驱动并按任务裁剪字段。
- 与 `constraint-aware-prompt-expansion` 的区别：本 skill 追求可比对的相似目标；后者在允许偏离时探索更多方向。

## E — 可执行步骤 (Execution)

1. **分开记录事实、推断与目标**
   - 事实：画面可直接看见的主体、颜色、光影、空间、构图；推断：可能的年代、镜头、材质或叙事；目标：必须保留与允许变化的特征。
   - 完成标准：每项都标有“可见/推断/待确认”之一。

2. **用四维形成可编辑提示词**
   - 依时间、主体、场景、风格组织描述；优先写目标必须保留的特征，对不确定项提供选项而非编造成事实。
   - 完成标准：提示词不含“原图提示词必然如此”的断言，并能说明每个关键字段来自哪里。

3. **生成、比对、只改偏差维度**
   - 用清单比对主体、光线、构图、色调、媒介；出现偏差时定位到对应维度再改写。
   - 完成标准：输出一份“保留/偏差/下一轮修改”记录；明确说明相似不等于复刻。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 参考图受版权、商标、肖像或平台规则限制而用户要求逐像素复刻；应先说明限制并改为提炼高层特征。
- 用户没有参考图，只有文字创意；用 `image-prompt-specification`。
- 用户想从同一主题发散大量不同风格，且不要求保留参考特征；用 `constraint-aware-prompt-expansion`。

### 作者在书中警告的失败模式

- 把 Agent 的反推结果当成原图的精确还原，会忽略模型无法完整复现参考图的限制。
- 不懂提示词结构就无法在 AI 反推不佳时有针对性地修改。

### 作者的盲点 / 时代局限

- 课程没有展开图片版权、风格模仿与个人肖像授权问题；实际商用必须另行核查。
- 参考图的 EXIF、镜头、后期流程通常不可从单张图可靠确定，不能伪装成已知事实。

### 容易混淆的邻近方法论

- “分析参考图”不是“保证复制原图”。
- 反推所得的结构化提示词可交给 `image-prompt-specification` 继续裁剪和补缺。
