# 权利与发布门

本文件用于发现阻断，不构成法律意见。

- `已确认可用`：用户说明拥有、获得许可或素材处于可用许可范围。
- `仅限内部探索`：权利未确认但只做私下试验；不默认允许发布。
- `发布受阻`：商业或公开发布涉及受保护角色、品牌、真人肖像、未授权素材或不明字体许可。

有授权时可把角色或品牌纳入锚点，但仍遵守许可范围。未授权时切换原创设计路线，只提取高层特征，不复制可识别角色设计、标志或专有名称。权利不明时可在标注后继续内部探索，但阶段 7 把公开发布状态视为硬失败。

同时检查真人肖像同意、商标规范、参考图片来源与许可、字体商业许可。金融内容不伪装为个性化投资建议；市场颜色、Ticker、价格和涨跌语义必须复核。

记录已确认事实、用户声明、无法验证项和发布阻断项。不要把用户未说明的授权写成“已授权”。
