# 权利与发布门

本文件用于发现阻断，不构成法律意见。

## 状态分类

- `已确认可用`：用户说明拥有、获得许可，或素材处于与当前用途相符的许可范围。
- `待核验`：来源、许可、用途、地域、期限、商业/公开发布或复用范围仍有关键缺口。
- `受阻`：适用权利尚未解决，或现有许可明确不覆盖当前制作、复用或发布用途。

权利结论必须绑定具体素材、角色/品牌、用途和发布范围。不要把“用户提供了文件”“仅供参考”或历史项目曾使用过，推断为当前项目已获授权。

## V5 硬规则

适用权利为 `待核验` 或 `受阻` 时，项目设为 `blocked`：

- 不调用图片生成或图片编辑模型；
- 不生成候选角色、风格压力测试或正式图；
- 不把候选资产晋级为 release，不写入 registry，也不执行外部发布；
- 可以继续非生成性的文字规划、权利核验、原创替代方案说明和受影响范围盘点。

增加确认次数、切换 `full_review`、降低工作流级别或用户口头说“先试试”都不能绕过权利阻断。解除阻断必须来自可定位的新证据，或把受影响元素替换/隔离为权利清楚的原创方案；随后只重算相关字段及下游。

已有、已授权素材的确定性盘点不等于获得对未解决元素的生成许可。若资产板会纳入权利不明的视觉资产，连 `candidate_preview` 也不得构建。

## 使用与发布

有授权时可把角色、品牌或参考图纳入锚点，但仍须遵守许可限定的用途、发布范围、署名、地域、期限和复用条件。未授权时切换原创设计路线，只提取不可识别的高层需求，不复制可识别角色设计、标志、专有名称或受保护表达。

同时检查真人肖像同意、商标规范、参考图片来源与许可、字体商业许可。金融内容不伪装为个性化投资建议；市场颜色、Ticker、价格和涨跌语义必须复核。

在 G0 和 Build Pack 中分别记录：已确认事实、用户声明、无法独立验证的信息、证据位置、适用范围、当前阻断和解除阻断的最小动作。
