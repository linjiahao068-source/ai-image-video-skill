<a id="risk-floor"></a>
## Risk floor 0 / 1 / 2

risk_floor 是模式选择的最低风险记录，不是新的用户门，也不能改写 G0/G1/G2 的含义。

| floor | 典型任务 | 最低建议模式 | 正式成图前拍板 |
| ---: | --- | --- | ---: |
| 0 | 信息完整、低风险原创单图、无精确身份/文字/权利风险 | direct | 0 |
| 1 | 需要用户选择创意方向、市场语义、构图或文案方案 | guided | 1（G0） |
| 2 | 多角色连续性、官方/设定级画风、品牌/产品、精确长文字、复杂资产或权利风险 | controlled | 2（G0+G1） |

新条件提高 risk_floor 时，记录升级原因并将模式提升到能承载该 floor 的最低模式；只增加尚未经过的标准门。不受影响且仍有效的 G0 字段不得因为风险升级而重复确认。risk_floor 降低也不能自动抹掉已发生的确认、来源或失效记录。

<a id="character-fidelity"></a>
## Character Fidelity Gate

满足任一项即把 risk_floor 提升到 2，并采用 controlled：

- 用户要求授权角色、品牌角色或明确的“官方/设定级”身份一致性；
- 两个以上重复角色出现在三格/三张以上序列中；
- 身份、性格、服装、产品或场景连续性是硬要求；
- 既往生成已出现身份漂移、角色串戏或表演越界。

G0 确认角色身份、故事职能、性格与行为边界。G0 通过后，standing authorization 允许后台生成候选角色资产；正式图仍须等 G1 视觉锚点包通过。

<a id="style-fidelity"></a>
## Style Fidelity Gate

满足任一项即把 risk_floor 提升到 2，并采用 controlled：

- 用户要求“官方画风”“设定级画风”或对特定授权参考高度一致；
- 一组图片必须保持相同线条、形状语言、上色、阴影、分格和气泡规则；
- 既往结果出现角色像但画风不像，或同一页不同格风格漂移。

角色卡只锁定“是谁、怎样表演”，不能单独锁定“怎样画”。G0 先确认可观察的风格合同和权利范围；G1 再提交候选风格资产、三件套预览与压力测试摘要。生成模型不能保证复刻所谓官方画风。

<a id="g0-contract"></a>
## G0：角色、故事、风格与权利

每条规则标记为：

- authorized_reference：用户确认可在当前范围使用的可见素材；
- user_confirmation：用户在 G0 明确拍板的项目规则；
- role_inference：后台角色的合理推测，必须显式展示，不得冒充确认；
- unknown：缺少证据，不能由模型补成“官方设定”。

若故事分工与角色规则冲突，G0 不能通过。例如，旧版本要求角色负责夸张动作，新要求又禁止夸张表演，必须形成新 G0 版本并让依赖字段失效。

### 角色合同

| 角色 | provenance | 身份不变量 | 故事职能 | 核心性格 | 动作强度 0–3 | 允许表情/动作 | 禁止表情/动作 | 说话方式 |
| --- | --- | --- | --- | --- | ---: | --- | --- | --- |

动作强度只用于项目内比较：0 静止/微表情；1 小幅反应；2 明显动作；3 极端肢体喜剧或高张力动作。不得把等级当作角色官方事实。

### 风格合同

| 维度 | 授权参考证据 | 必须保持 | 允许变化 | 禁止偏差 | 验收方法 |
| --- | --- | --- | --- | --- | --- |
| 线条与轮廓 |  |  |  |  |  |
| 形状与比例语言 |  |  |  |  |  |
| 五官、表情符号与腮红 |  |  |  |  |  |
| 色板、上色与阴影 |  |  |  |  |  |
| 背景密度与道具简化 |  |  |  |  |  |
| 分格、气泡与字体气质 |  |  |  |  |  |

“像某作品”不是可执行验收条件。必须转换为可观察特征，并保存来源、版本与权利范围。不得把生成出的偏差反向写成风格合同。

<a id="candidate-assets"></a>
## 候选资产最低内容

- 单角色身份卡：正面、3/4、侧面或背面；轮廓、五官比例、颜色和标志细节。
- 表情与动作卡：中性、常见情绪、允许的最高强度；至少一个禁止示例用文字说明。
- 多角色比例卡：相对身高、体型、同框距离和道具尺寸。
- 场景卡：建立视角、关键行动视角、空间关系；复杂环境单独生成。
- 产品/道具卡：整体、关键细节、精确文字或标志的独立核验资产。
- 风格卡：线条、形状语言、色板、材质、阴影、背景密度、分格与气泡规则。

高风险漫画至少分别生成单角色身份卡、表情动作卡、多人比例卡和风格锚点卡。场景或精确道具按职责另拆。候选资产是 generated_candidate，不是事实来源。

## G1：唯一一次视觉锚点拍板

G1 只适用于 controlled，并且必须作为一个可审计整包提交：

1. 候选角色、风格、场景和道具资产；
2. candidate_preview 带字总览、无字 clean groups 与 manifest/build report；
3. 身份、表演、风格、遮挡和关键道具压力测试摘要；
4. 各专业角色自检与主 Agent 独立审核；
5. provenance、权利、SHA-256、拆分和 effective validity 摘要。

G1 不是通用“是否生成”授权；制作/生成请求已经形成 standing authorization。G1 也不拆成角色卡、风格卡、三件套、压力测试等多次用户确认。用户对整包做一次拍板。

candidate_preview 可含候选资产并用于 G1 阅读，但不能进入 registry，也不能直接用于正式图。未确认、哈希变化、来源不明、标签溢出、含文字 clean group 或拆分超限均阻断 G1。

<a id="asset-release"></a>
## Asset release

G1 通过后自动执行，不新增第三次用户确认：

1. 把 G1 选择的候选资产标记为 approved；
2. 核对权利范围、合同版本、文件存在性与 SHA-256；
3. 用 approved 资产重建 release annotated、release clean groups 和 release manifest；
4. 运行确定性构建检查并记录 build report；
5. 仅在全部有效时设置 registry_eligible=true；
6. 将 release 状态写入 Build Pack 的 provenance 和 effective validity。

任何源资产、权利、合同、标签或哈希变化都让对应 asset release 及其依赖字段失效。恢复时保留有效 G0，只回到 G1 修复受影响锚点；旧 release 保留为历史记录但不得用于正式生成。

## 正式生成输入

- direct/guided 不凭空引入 G1 或 asset release。
- controlled 只使用 G1 后自动构建的、与当前任务相关的 release 无字 clean groups。
- 清单硬约束同时进入文本提示词。
- annotated、candidate_preview、contains_text=true 资产、旧 release 和不相关 clean group 默认不得传给图片模型。
- 精确文字资产独立保存并走确定性排字/合成，不混入 clean group。
- 正式图生成后自动进入 G2 QA；不追加候选选择、QA 启动或路径确认。

<a id="field-validity"></a>
## 字段失效与恢复

| 变化 | 直接失效 | 默认保留 | 返回 |
| --- | --- | --- | --- |
| 故事、对白、角色职能、用途、权利 | 对应 G0 字段及依赖 G1/正式图 | 无关 G0 字段、历史版本 | G0 |
| 身份/风格锚点、场景/道具候选、压力测试 | 对应 G1 字段、asset release、正式图 | 有效 G0 | G1 |
| approved 源文件哈希变化 | 对应 asset release、G1 下游、正式图 | 有效 G0 与无关资产 | G1 |
| 单次生成偏差 | 当前正式图与 G2 | G0、G1、asset release、standing authorization | 后台自动返修 |

恢复时读取 project-state、Build Pack、provenance 和 effective validity，计算最早无效门；不得默认从头开始，也不得从聊天记忆猜测缺失确认。

## 漫画与序列图片

```markdown
| 格 | 叙事功能 | 可见事件 | 角色职能 | 表情/动作强度 | 对白/字幕（逐字） | 视觉焦点 | 与上一格变化 | 角色合同冲突 |
| ---: | --- | --- | --- | --- | --- | --- | --- | --- |
```

每格只承担一个主事件，先保证因果链，再增加表情、道具和风格细节。每格都要对照已确认的角色合同；角色职能、性格或禁区冲突时先返工故事。明确阅读方向，统一角色外观、服饰、道具和市场颜色语义，对白逐字确认且气泡不得遮挡关键表情或动作。

常用但不强制的四格节奏是：建立愿望或规则 → 行动并出现不利变化 → 反向行动或自我安慰 → 结果反转。第四格必须依赖前面已经建立的信息。

触发角色或风格保真门时，正式漫画前先完成对应资产卡和压力测试；连续两轮出现分格、文字、身份或顺序硬失败，切换为分格生成再组装。

漫画中的对白、标牌、对象标签和页脚都是叙事元素。G0 锁定存在性和逐字内容，美术指导锁定可见层级与实际容器；`comic_display` 下，过小、未居中或不符合锁定行组均不得通过。

股票梗中，买入后走势下跌、卖出后走势上涨；颜色先按目标市场确认；不要把漫画包装为投资建议。
