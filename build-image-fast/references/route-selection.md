# 生成路线选择

| 主要风险 | 首选路线 | 原因 |
| --- | --- | --- |
| 快速验证氛围或方向 | 快速路线 | 一次完整生成，决策成本低 |
| 多格顺序、精确文字、版式 | 稳定路线 | 可分格/分区验收并局部返工 |
| 角色、产品、品牌身份 | 稳定路线 | 先建立锚点，减少漂移 |
| 现有图大部分合格 | 编辑路线 | 避免重新生成破坏通过项 |

快速路线默认 1 张候选，允许非关键细节漂移。连续两轮发生文字、身份、分格或版式硬失败时切换稳定路线。

稳定路线先建立角色/产品锚点，再按面板或区域生成，使用统一画布、安全区和色板验收；精确文字需要可用排版工具；组装后复查一致性和阅读顺序。

编辑路线明确唯一变更项和必须保持的构图、身份、文字、光线、尺寸。每轮只处理一个失败变量。

用 `capability-cost-fit` 分开草稿与精修：草稿验证概念；精修保证阅读性、保真、文字和目标尺寸。
