# 自适应工作流

本文件决定用户要参与多少次，不决定模型如何生成。先选 `workflow_mode`，再独立选 `generation_route`；不要因使用稳定生成路线就自动增加用户确认。

## 工作流模式

| `workflow_mode` | 适用条件 | 正式成图前的阻塞拍板 | 默认行为 |
| --- | --- | ---: | --- |
| `atomic` | 只写提示词、分析参考图、比较模型或其他单点请求 | 0 | 路由到对应原子 Skill，不建完整项目或 Build Pack |
| `direct` | 单张、目标明确、低风险、允许非关键细节漂移 | 0 | 用户生成请求即授权默认 1 张候选 |
| `guided` | 单项中风险，或仍有一个会明显改变结果的选择 | 1：G0 | 合并内容和视觉方向后一次拍板 |
| `controlled` | 任一硬风险或两个以上中风险 | 2：G0＋G1 | 先锁内容，再锁资产与保真证据 |
| `edit` | 已有图片大部分合格，只改一个明确变量 | 通常 0 | 建立变更/保留合同后直接编辑和复验 |

默认 `review_mode=adaptive`。只有用户主动要求逐阶段审片时设为 `full_review`；全程审片不能降低硬门，也不改变八阶段内部职责。

## 风险模块

按最高后果判断，不计算平均分。为每个启用模块记录 `low / medium / hard` 和可核验证据：

| 模块 | 中风险示例 | 硬风险示例 |
| --- | --- | --- |
| `semantic_lock` | 重要标题、单一数据、明确情绪转折 | 逐格因果、金融/医疗等领域语义、长段逐字文案 |
| `fidelity_lock` | 单张角色或产品近似稳定 | 多张重复身份、品牌产品、指定风格、角色行为合同 |
| `rights_lock` | 权利范围已声明但待写入交付 | 适用授权、商业用途或公开发布范围未解决 |
| `layout_lock` | 重要比例、安全区或阅读顺序 | 精确排版、多格顺序、数据关系不能错 |
| `reuse_audit` | 可能复用但未要求登记 | 系列资产、三件套、跨项目复用或完整复现 |

判定顺序：

1. 只需单点产物时选 `atomic`；已有图且唯一变更清楚时选 `edit`。
2. 适用权利或关键输入未解决时先设 `blocked`，不得生成。
3. 任一硬风险或两个以上中风险选 `controlled`。
4. 仅一个中风险选 `guided`。
5. 其余完整图片请求选 `direct`。

图片总编在首次回复给出推荐模式和一句理由，不让用户先填写流程问卷。用户可要求更高控制级别；要求降级时只在风险已被真实移除或隔离后接受。

## 何时询问用户

仅当一个问题同时满足以下条件时，放入 G0/G1 或单独阻断：

1. 会明显改变可见结果、核心语义、身份、权利、成本或发布范围；
2. 生成后难以低成本撤销；
3. 无法从用户文本、已确认素材或既有合同可靠推断。

可逆构图细节、普通配色微调、提示词措辞、负面词、模型常规参数、文件名、版本号、哈希、清单字段、内部 QA 和交接由团队决定并记录。每个决策包最多提出三个高影响问题；其余写成明确假设或 `agent_decision`。

## 授权与委托

- 用户明确要求“制作/生成/做成图片”时记录 `standing_authorization`，范围为当前推荐工作流下默认 1 张候选。
- `standing_authorization` 不覆盖额外候选、高成本档位、外部发布、跨项目复用或新增受保护素材。
- 用户说“按推荐方案推进，其他可逆细节你决定”时记录 `delegated_decision`、范围和来源；不要写入 `user_confirmed`。
- 用户自然语言“确认、通过、就按这个、采用推荐方案”明确指向当前 G0/G1 时即可锁定，不要求复述版本号。

## 升级、降级与退出

- 新条件触发更高风险时立即升级模式，保留仍有效字段，只补缺少的决策包。
- `direct/guided` 连续两次出现文字、身份、分格或版式硬失败时升级 `controlled`，并把生成路线切为 `stable`。
- `edit` 出现第二个变更变量、保留范围不清或上游内容冲突时退出编辑模式，重算 `guided/controlled`。
- 风险被删除、替换为原创方案或通过确定性后处理隔离后才允许降级；仅口头要求“少问一点”不能绕过底线。
- 用户选择 `full_review` 时保留该偏好，直到用户明确切回 `adaptive`。

## 典型路由

- “画一只原创小熊在雨里等公交，直接生成”：`direct + fast`，0 次前置拍板。
- “做中文促销海报，标题必须逐字正确”：`guided + stable`，一次 G0；排字和 QA 在后台。
- “三个授权角色连续四格，形象和性格都要稳定”：`controlled + stable`，G0 锁故事与角色，G1 锁资产与压力测试。
- “只把现有图的手机改成股票交易软件，其他不变”：`edit + edit`，变更范围明确时直接执行。
